# You-are-an-idiot-com-Python-Tkinter-
Projeto de estudo de tkinter e pygame no Python inspirado no antigo meme do You are an idiot!

## 📖 Sobre

Projeto desenvolvido para estudar interfaces gráficas em Python utilizando **Tkinter** e reprodução de áudio com **Pygame**.

O projeto foi inspirado no clássico meme da internet **"You Are An Idiot"** e foi recriado apenas como um exercício de programação para aprender novos conceitos.

O que eu aprendi: 
- Criar janelas com topLevel
- Manipulação de imagens com PhotoImage
- Evento de janelas('WM_DELETE_WINDOW')
- Uso de lambda
- Organização de janelas e imagens com listas!
- E mais...

## 🛠️ Tecnologias

- Python 3
- Tkinter
- Pygame


  Projeto desenvolvido exclusivamente para fins educacionais e prática de programação em Python.
